# Or7 Works — Kit de planejamento e execução, Fase 01

Este arquivo ZIP é um **kit documental** para entregar ao Claude Code junto com o repositório da aplicação. Não é o site pronto, nem inclui logos/imagens originais ou código copiado de bibliotecas externas.

## Uso
1. Extraia a pasta `or7works_fase01`.
2. Inclua esta pasta no contexto/ambiente do Claude Code e disponibilize o repositório real onde o Or7 Works será criado.
3. Forneça os logotipos originais aprovados separadamente, caso disponíveis.
4. Abra `prompt/PROMPT_MESTRE_CLAUDE_CODE.md` e envie seu conteúdo ao Claude Code. Peça início pela Etapa 01.
5. Revise checkpoints A/B/C/D. Não autorize deploy antes de homologação.

## Conteúdo
- prompt/: prompt mestre completo de quatro etapas
- docs/: escopo, Design System, arquitetura e roadmap
- referencias/: links escolhidos nas 40 categorias (CSV e Markdown)
- checklists/: critérios de aceite

## Proveniência
Plano consolidado a partir das decisões da conversa e princípios do Or7 Creative System. Os arquivos originais históricos de skills/repositórios de terceiros, logos e projeto de código não foram copiados para este ZIP. URLs ainda precisam de validação individual de disponibilidade e licença pelo implementador. Nenhuma instalação ou teste de runtime foi realizada.
